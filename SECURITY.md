# Security Policy

## Supported Versions

This is a personal GitHub profile repository (no application code/releases), so there are no versioned releases to track for security updates.

## Reporting a Vulnerability

If you discover a security vulnerability in any of my projects, please report it privately rather than opening a public issue.

- Use [GitHub's private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing/privately-reporting-a-security-vulnerability) on the affected repository (Security tab → "Report a vulnerability").
- If that isn't enabled on the repository, open a GitHub issue asking me to enable it, without disclosing details, and I'll follow up with a private channel.

Please include as much detail as possible (steps to reproduce, affected component, potential impact) so the issue can be triaged quickly. I aim to acknowledge reports within 5 business days.
